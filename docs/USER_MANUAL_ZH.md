# 用户手册

适用项目：`g6-english-assessment-vercel` 当前版本  
适用对象：学生、教师、教务/管理员

## 1. 系统简介

本系统用于在线测评与试卷管理，支持以下核心场景：

- 学生在线进入试卷并完成作答
- 教师管理题库、试卷和用户权限
- 系统保存测评记录，并生成详细报告与 PDF

当前系统按学科提供入口，常见学科包括：

- English
- Math
- Vocabulary

## 2. 角色与权限

系统主要分为两类用户。

| 角色 | 主要权限 |
| --- | --- |
| 学生/普通学科用户 | 登录、进入已开放试卷、填写学生信息、完成测评 |
| 教师/全工作台用户 | 除学生功能外，还可进入 `Teacher Tools`，管理题库、试卷、测试记录和用户 |

说明：

- 注册时需要输入管理员提供的邀请码。
- 邀请码会决定你能访问哪些学科，以及是否拥有教师工作台权限。
- 如果你登录后看不到某个学科、某份试卷或 `Teacher Tools`，通常是权限未开通。

## 3. 登录与注册

### 3.1 注册账号

如果你是第一次使用系统：

1. 打开注册页。
2. 输入用户名。
3. 输入密码并确认密码。
4. 输入管理员提供的邀请码。
5. 提交注册。

建议：

- 用户名保持简短且易识别。
- 邀请码区分权限，请不要随意共享。

### 3.2 登录账号

已有账号时：

1. 打开登录页。
2. 输入用户名和密码。
3. 登录后进入首页。

## 4. 学生使用流程

### 4.1 选择学科与试卷

登录后，首页会显示你有权限访问的学科和试卷。

操作步骤：

1. 进入对应学科。
2. 选择一份试卷。
3. 点击 `Start Assessment`。

如果某份试卷没有显示，可能原因有：

- 该试卷尚未发布给学生
- 你的账号没有该学科权限

### 4.2 填写学生信息

正式开始前，系统会要求填写学生信息。

- `Name` 为必填
- `Grade` 为选填

填写完成后：

- 首次进入点击 `Start Assessment`
- 如果之前已经开始过，按钮会显示为 `Continue Assessment`

### 4.3 开始作答

进入答题页后：

- 左侧侧边栏会显示各部分进度
- 可以在不同 section 之间切换
- 页面会实时保留当前作答状态，方便在同一次会话中继续

不同题型可能包括：

- 选择题
- 多选题
- 阅读题
- 写作题
- 听力题

使用说明：

- 听力大题会附带音频，先播放再作答
- 多选题会提示可选择的数量
- 写作题和主观题请直接在页面输入答案

### 4.4 中途退出

答题页右上角提供 `Exit Test`。

请注意：

- 点击退出后，系统会弹出确认框
- 如果确认退出，当前答案和作答进度会被清空
- 清空后会返回试卷选择页

建议学生不要在未确认提交前随意退出。

### 4.5 提交试卷

全部完成后，点击页面底部或相应区域的 `Submit Assessment`。

提交时系统会：

- 检查是否有未作答题目
- 弹出确认提示
- 提醒提交后不能继续修改

建议提交前先检查：

- 姓名是否正确
- 听力题、阅读题是否都已填写
- 写作题内容是否完整

### 4.6 提交后的结果页

提交后会进入上传与处理页面。

此页面的作用是：

- 上传学生答案
- 执行系统处理和评分
- 生成后续报告数据

请务必注意：

- 在进度到达 100% 前，不要关闭页面
- 页面显示上传完成后，才可以安全离开

当前版本中，详细分析报告、分项评分、逐题回顾和 PDF 下载不直接在学生作答页展示，而是在教师端查看。

## 5. 教师使用流程

教师账号登录后，除正常选卷功能外，还可以进入 `Teacher Tools`。

`Teacher Tools` 是教师和管理员进行内容维护与结果查看的主工作台。

常用模块包括：

- `Paper Generator`
- `Question Bank`
- `Paper Manager`
- `Test History`
- `User Manager`

部分试卷编辑工作还会进入 `Question Intake` 页面完成。

### 5.1 Teacher Home

教师首页通常用于：

- 选择学科
- 查看当前学科试卷
- 进入教师工具页

如果你有多个学科权限，可以在不同学科之间切换。

### 5.2 Paper Generator

页面名称：`Paper Generator`

用途：

- 管理试卷名称
- 管理考试体系
- 管理 Part / Section 配置
- 管理教材单元或练习筛选条件

系统中的 `Question Intake` 和题库录入会直接读取这里的配置。

适合在以下情况使用：

- 新增一个考试体系
- 调整某个学科的 Part 结构
- 配置教材练习单元

简单理解：

- `Paper Generator` 决定“试卷结构和标签体系”
- 后续录题、组卷会基于这些结构进行

### 5.3 Question Bank

页面名称：`Question Bank`

用途：

- 查看已保存的题库条目
- 按关键词搜索题目
- 按考试体系筛选
- 按题型筛选
- 查看每道题的标签和内容预览

适用场景：

- 检查某类题是否已经录入
- 核对标签是否正确
- 筛选可用于随机组卷的题目

如果某个学科的标签体系还没建好，通常应先去 `Paper Generator` 完成配置。

### 5.4 Question Intake / Paper Builder

页面名称会根据当前状态显示为：

- `Question Intake`
- `Edit ... Question Set`

用途：

- 手动录入题目
- 新建整份试卷
- 编辑已有试卷
- 上传图片或听力音频
- 保存草稿、发布、或另存为副本

教师常见操作：

1. 进入 `Question Intake`
2. 选择学科
3. 填写标题和说明
4. 新建 section / question
5. 上传所需图片或音频
6. 点击 `Save Draft` 保存草稿
7. 点击 `Publish Paper` 或相应发布按钮正式发布

说明：

- 听力大题支持上传音频文件
- 图片题、场景题可上传配图
- 发布后，试卷才可能被学生看到

### 5.5 Paper Manager

页面名称：`Paper Manager`

用途：

- 管理学生端真正可见的试卷
- 查看试卷当前是否 `Published`
- 将试卷设为显示或隐藏
- 删除旧试卷
- 跳转进入编辑页面

建议教师把这里理解为“学生端上架管理页”。

一个常见流程是：

1. 在 `Question Intake` 完成试卷内容
2. 在 `Paper Manager` 检查是否已发布
3. 确认学生端可见状态是否正确

如果学生反馈看不到试卷，首先检查：

- 该试卷是否已发布
- 该试卷所属学科是否和学生权限一致

### 5.6 Test History

页面名称：`Test History`

用途：

- 查看所有已保存的测评记录
- 按学生姓名、试卷名称或记录编号搜索
- 点开单条记录展开完整报告

这里是教师查看报告的核心页面。

报告通常包括：

- 综合得分
- 分项表现
- 逐题回顾
- 写作或口语评价
- PDF 下载入口

重要说明：

- 学生提交后的“上传完成页”只负责上传和处理
- 真正的详细报告和 PDF 下载，请进入 `Teacher Tools → Test History`

### 5.7 User Manager

页面名称：`User Manager`

用途：

- 管理学生和教师账号
- 调整账号是否启用
- 调整学科访问权限
- 删除不再使用的账号

当前逻辑中：

- 状态和学科权限修改通常会自动保存
- 删除用户前请先确认是否仍需保留历史记录关联

适用场景：

- 为新老师开通权限
- 为学生开放新的学科
- 暂停已停用账号

## 6. 常见工作流程示例

### 6.1 发布一份新试卷

推荐顺序：

1. 在 `Paper Generator` 配好考试体系、Part 和筛选项
2. 在 `Question Intake` 录入题目内容
3. 保存草稿并检查内容
4. 发布试卷
5. 在 `Paper Manager` 确认该试卷为可见状态
6. 让学生登录后开始作答

### 6.2 修改一份已存在的试卷

推荐顺序：

1. 进入 `Paper Manager`
2. 找到目标试卷
3. 点击 `Edit`
4. 修改内容
5. 保存或重新发布
6. 返回 `Paper Manager` 确认状态

### 6.3 查看并下载测评报告

推荐顺序：

1. 进入 `Teacher Tools`
2. 打开 `Test History`
3. 搜索学生姓名或试卷名称
4. 点击对应记录展开完整报告
5. 在报告页中下载 PDF

## 7. 常见问题

### 7.1 为什么我看不到某个学科？

可能原因：

- 注册时使用的邀请码没有该学科权限
- 管理员尚未为你的账号开启该学科

处理方式：

- 联系管理员检查账号权限

### 7.2 为什么学生看不到试卷？

优先检查：

- 试卷是否已经发布
- 试卷是否在 `Paper Manager` 中处于可见状态
- 学生账号是否有对应学科权限

### 7.3 为什么提交后没有直接看到完整报告？

这是当前系统设计逻辑。

学生提交后先进入上传处理页，完整报告和 PDF 下载统一放在：

- `Teacher Tools → Test History`

### 7.4 听力题音频在哪里配置？

教师在 `Question Intake` / 试卷编辑页中，可以为听力大题上传音频文件。学生进入对应部分后即可播放。

### 7.5 中途退出会怎样？

如果在答题过程中点击 `Exit Test` 并确认退出：

- 当前答案会被清空
- 当前作答进度会被清空
- 页面会返回试卷选择页

### 7.6 谁可以管理用户？

只有拥有教师工作台权限的账号才可以进入 `User Manager`。

## 8. 使用建议

- 学生答题前先确认姓名填写正确
- 听力题建议佩戴耳机并先测试音量
- 提交后保持页面打开，直到上传完成
- 教师发布试卷后，最好用学生权限账号实际检查一次是否可见
- 教师查看正式报告时，统一从 `Test History` 进入
